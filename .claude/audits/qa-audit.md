**Gotcha de teste encontrado nesta rodada (documentado para evitar repetição):** ao reusar um mock de repository em vários testes de uma mesma classe, um `when(repo.metodo(any())).thenAnswer(...)` "genérico" registrado num `@BeforeEach`/helper comum e reaproveitado por testes que também fazem `when(repo.metodo(idEspecífico)).thenReturn(...)` pode quebrar com `NullPointerException` — o `when(...)` do Mockito **executa a chamada real no mock** para gravar o matcher, e se já existir um stub genérico ativo cujo `thenAnswer` depende de estado ainda não inicializado (ex.: uma entidade só populada por um `save()` que este teste específico nunca chama), a própria configuração do stub explode antes do teste começar. Resolvido separando os helpers de stub: um específico para os testes que precisam do stub genérico pós-`save()`, outro mais enxuto para os que já stubam o id explicitamente (`QuoteServiceTest.stubCriarComuns()` vs `stubPrecificacaoEMapeamento()`).
